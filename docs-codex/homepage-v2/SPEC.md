# 首页 V2 与智能助手交互原型需求

## 依据与范围
以 docs-work/ui/网站首页V2.xmind 为首页内容依据，现状导图仅供对比。助手遵循同目录五张界面参考图，采用浅色工作台和 SVG 图标。保留首页首屏、三维场景和六个导航锚点。

## 首页节点映射
- 关于：保留介绍。
- 能力：全栈（Python、FastAPI、Java、Spring Boot、TypeScript、MySQL / PostgreSQL、Docker、Redis）；智能体架构（LangGraph：Workflow、Plan & Execute、ReAct、Reflection、Supervisor；工具调用、上下文工程、记忆、人机协作）；RAG 与知识治理（Embedding、BM25、RRF、Rerank、Milvus、知识治理）；评估与可靠性（Agent Evals、Tracing、Langfuse、故障恢复、成本与延迟优化、审计与安全边界）。
- 作品：RAG、智能助手、办公自动化智能体；助手整卡键盘可访问，进入 /assistant，标明交互原型。
- 构建：知识中心、企业数字员工、ChatGPT Harness。
- 探索：Codex、DSH、Pi、Hermes、PyTorch；移除 OpenClaw。
- 规划：后端工程师 → Agent 工程师（当前）→ Agent 架构师 → FDE（前沿部署工程师）。

## 助手页面与闭环
路由：/assistant、/assistant/tools、/assistant/skills、/assistant/mcp、/assistant/agents、/assistant/files、/assistant/chat/[id]。共享侧栏、最近聊天、输入框和返回网站。
聊天支持新建、切换、搜索、重命名、删除，模拟逐段输出、停止、失败重试。每条消息选择一种能力，可附多个文件，通过 @ 或详情选择能力。工具、技能、连接器、智能体各有六个初始样例，支持搜索、分类、详情、常用管理；技能支持本地 Markdown 导入和删除个人技能，MCP 支持配置、模拟连接/断开/失败/重试。文件库支持元信息模拟上传、搜索、删除、附件选择。

## 数据边界
纯前端模拟，无业务后端、模型、外网调用或权限系统。文件仅保存元信息；技能保存文本。React Context + reducer 集中管理，localStorage 版本化恢复后才写入；损坏数据恢复种子，存储不可用退回内存并提示；刷新中的生成改为已停止。重置须确认。所有页面标明“交互原型 · 模拟数据”。

## 验收
单元测试、lint、生产构建通过；浏览器验证跳转/直达/刷新/前后退、四种能力聊天、上传/配置/常用/重置/错误恢复、桌面与手机布局、键盘与弹窗焦点、首页双向滚动/锚点/减少动态效果。自动结果与人工视觉核验分开记录。

## 实施时确定的细节
- 会话与新聊天分别保存草稿；目录页面使用新聊天草稿。历史会话 URL 直达后恢复该会话草稿。
- 重试明确作用于所点击的消息；生成中禁止启动另一条重试。刷新中的输出标为已停止，可原位重新生成。
- 历史消息保留能力和附件名称快照；删除个人技能或文件同时清理全部草稿引用，重试时说明已失效资源。未连接 MCP 的发送与重试均引导配置。
- 技能只导入 .md 文本（最大 256 KiB），拒绝空内容；个人技能名称最多 80 字符。连接配置为有效 HTTP/HTTPS 演示地址，不进行网络访问。
- 模拟输出按三段显示；技能展示完整步骤，工具/连接器/智能体展示各自不同的过程。
- 弹窗及移动侧栏支持 Escape、焦点圈定与返回。移动侧栏关闭后隐藏于键盘和无障碍树。
