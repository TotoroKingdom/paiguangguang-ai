# TASK-01 · Homepage Content Alignment & Hero AI Core Polish

> Status: Ready  
> Scope: Homepage only  
> Priority: High  
> Goal: 对齐首页内容结构与个人表达，同时优化 Hero 右侧 AI Core / “太阳系”视觉表现。  
> Constraint: 不重做整体视觉风格，不推翻现有拟态风格与 3D 基础，只做内容校正与局部视觉优化。

---

## 1. 背景

首页前端重构已经基本完成，整体视觉方向（拟态风格 + 3D 元素）已经接近预期。  
但当前版本仍存在以下问题：

1. 首页“关于”文案偏商业化，更像销售型产品介绍，而不是表达个人对 AI 的理解与愿景。
2. 导航结构与页面结构未完全对齐，缺少明确的六阶段映射。
3. “能力”栏目当前更偏工程能力表述，未准确体现“技术栈展示”的需求。
4. Hero 右侧 AI Core / 太阳系视觉仍不够圆润，色彩层次不明显，行星与文字关系不够协调。

因此，本任务聚焦于：

- 首页信息架构和文案校正；
- Hero 右侧 3D 视觉优化。

---

## 2. 目标

完成后，首页应达到以下目标：

### 内容目标

首页结构清晰回答以下 6 个问题：

1. 我是谁
2. 我的技术栈
3. 我的作品
4. 我正在构建的作品
5. 我正在探索的项目
6. 我的职业生涯规划

### 视觉目标

Hero 右侧 AI Core / 太阳系应做到：

- 轨道更圆、更稳定；
- 颜色更丰富但仍克制；
- 行星大小、位置与层级更协调；
- 行星与文字标签视觉关系更统一；
- 保持高级感，不像玩具，也不像默认 Three.js Demo。

## 4. 六阶段结构定义（必须严格对应）

首页一级结构必须严格按照以下顺序与语义展示：

### 01 / 关于

对应含义：

- 我是谁
- 我对 AI 的理解
- 我正在探索什么方向

要求：

- Hero 主文案回到“个人愿景 / 技术理解”
- 不要继续使用偏销售或偏商业交付导向的表达

建议表达方向：

> 我在探索，AI 如何从模型走向智能体。  
> 我关注的不只是模型能够回答什么，  
> 而是它如何拥有知识、记忆、工具与执行能力，  
> 最终形成能够完成真实任务的智能系统。

可以保留：

- AI Agent Engineer
- AI 智能体工程师
- Backend → AI Application → Agent Engineering → Agent Architecture

但整体语气必须更个人化、技术化、探索化。

## 6. 文案语气约束

这是一个**个人长期技术主页**，不是商业官网。

### 文案应该：

- 个人化

- 克制

- GitHub

## 7. Hero AI Core / 太阳系视觉优化要求

### 问题

当前 Hero 右侧 3D 视觉存在：

- 轨道不够圆
- 结构略散
- 色彩偏弱
- 行星、轨道、标签之间不够统一
- 看起来还不够“成体系”

### 优化目标

在不推翻现有 3D 基础的前提下，把它优化成一个更协调的“AI Core / Solar System”。

### 必做优化点

#### 7.1 轨道更圆

- 轨道线条应更接近完整圆形或稳定椭圆
- 不要出现明显变形或视觉重心偏移
- 不要让轨道看起来像随意摆放的装饰环

#### 7.2 中心更稳定

- 中央 Core 更明确
- 视觉中心要稳，不要被某个行星抢走中心感
- 中心发光/材质可以轻微增强，但保持克制

#### 7.3 加入色彩

允许引入柔和的 AI 色彩体系，例如：

- 蓝紫
- 青蓝
- 淡紫
- 柔和高光白

推荐原则：

- 每颗行星可有轻微差异色
- 轨道线可用极淡颜色
- 保持当前拟态浅色背景兼容
- 不要做高饱和赛博朋克

#### 7.4 行星更协调

- 行星大小有层级，但不要差异过大
- 分布更均衡
- 与轨道关系更自然
- 不要让某颗行星显得突兀

#### 7.5 文字标签更协调

如存在文字标签（如 Agent / RAG / Tool / Memory / LLM）：

- 文本颜色与对应行星色彩要更协调
- 标签位置不要挡住主体
- 标签与行星的距离要统一
- 标签不要显得像随意漂浮的注释

#### 7.6 动效保持克制

- 可保留缓慢旋转 / 轨道运动 / 轻微浮动
- 不要大幅加快动画
- 不要增加强烈粒子特效
- 不要破坏当前高级感
